# 沪电股份 · 策略实验室

交互看板：**https://wccwcc20260703.github.io/hudian-backtest-dashboard/**

自选 2023-10-09 至 2026-10-08 的日期区间，重新模拟现金账户，对比 D（反转与业绩门槛）、H（三状态自适应）和持有基准。日线标记每日实际模拟买卖；点击交易日查看 48 根 5 分钟 K 线、逐笔成交及策略状态。支持修改本金、5/10/20 bp 滑点、下载成交 CSV。

## 运行与验证

网站为静态 HTML/CSS/ES modules，不依赖自有服务器、登录、API 密钥或外部 CDN；实时行情使用腾讯公开接口。ECharts 6.1.0 随仓库提供。

```sh
python3 -m http.server 8793 --directory docs
# 打开 http://localhost:8793
npm test
```

先执行 npm ci 安装固定版本图表依赖，再运行测试。15 组独立 Python 原始回测作为基准，覆盖完整三年、单日、子区间、小本金及不同滑点；32,390 个数值（包括每日净值、仓位、逐笔成交、费用和回撤）误差须小于 0.000001 元。参考输出由原研究 `engine.py` 生成，不是 JavaScript 自测快照。

## 回测含义

- 日期区间含首尾；休市日期向区间内交易日对齐。每次从现金开始重新计算，不截取、平移旧净值。
- 指标和自适应模型保留所选区间之前的历史预热；参数固定，不利用所选区间重新选参。`docs/data.json` 中的逐日目标是原研究冻结信号，不是盘中看到未来后生成。
- 主动策略按前日目标减少时 09:45、其他情况 10:00 发出目标；执行最多持续 5 根 K 线，允许分批。比较的是目标仓位变化，而非账户实际仓位变化，区间重新开始也保留该时点规则。
- T+1，100 股买入单位；单次最多占前一根 5 分钟 K 线成交量 1%；涨跌停限制；不利滑点并取整到分。佣金万 2.5，最低 5 元；过户费十万分之一；卖出印花税万 5。默认本金 100 万元。D / H / B 没有借贷；L 融资模型允许净现金为负，不做空股票。
- 基准首日 09:35 开始建仓，最多 5 根 K 线，不保证一定买满。策略和基准都受相同成交容量约束。期末不强平，现金不计息。
- 主动策略分红统一预扣 20%，持有基准为税前现金分红，均不自动再投资。这一不对称设定偏保守。
- 最大回撤使用全部 5 分钟估值和初始本金，收盘以真实日线收盘价估值；净值已扣交易费用。曲线「相对基准」是收益率差（百分点），不是相对财富比。
- 日线三角形为当日同方向成交量加权均价，日内三角形为逐笔模拟成交价。图轴为 K 线起始时间（最后一根 14:55）；回撤估值时间为 K 线结束时间（最后为 15:00）。

## 策略

D：使用前一交易日 Wilder RSI(2)，在最新公告净利润同比 > 0 时，RSI < 35 配置 100%、RSI > 60 配置 0%、中间 50%；业绩条件不满足空仓。

H：过去 126 个已知结果中（当天 d 只使用 t ≤ d−2 的 10:00 至下一日 09:45 复权收益），业绩合格且低 RSI、高 RSI 两组各 ≥ 20 个样本，低组均值及低减高均超过 0.2% 时使用 D 的反转配置；否则价格在 MA60 上且 MA120 高于 20 天前时配置 100%，其他时候 0%。财报必须公告日严格早于交易日。

背景状态是 H 的「趋势参与 / 反转交易 / 防御空仓」，不是事后准确划分涨跌区间。没有针对未来真实最优买卖点的保证。

## 数据与局限

快照含 727 个交易日、34,896 根 5 分钟 K 线。分钟和日线主要来自 BaoStock，目标期日线 OHLC 与腾讯数据交叉检查一致；分钟最高/最低与日线存在差异，分钟未获独立逐笔数据验证。历史财报公告版本未逐份审计。历史回测快照不会自动更新；今日报价和分时从腾讯公开接口每 1 秒刷新（可能有源端延迟）。连接失败时明确标注缓存快照及源时间，未完成交易日不纳入历史回测。

**D 和 H 是观察历史后选出的研究候选，不能视为未见样本验证。** D 在 24 个滚动一年窗口中仅 8 个跑赢持有，旧时期曾亏损；H 对学习窗口与滑点敏感。历史回测不代表未来收益或真实可成交性。

## 文件

- `docs/engine.js`：浏览器 / Node 通用账户执行引擎。
- `docs/app.js`：日期选择、图表联动、成交 CSV。
- `docs/data.json`：原始行情、现金分红、冻结因果信号和事前指标快照。
- `tests/python-fixtures.json`：独立 Python 回测参考结果。
- `scripts/export_research.py`：从原研究目录重新导出快照与参考结果（需要原研究环境及数据）。

部署使用 GitHub Pages，发布源为 `main` 分支 `/docs`，无需构建步骤。更新数据后应同时更新页面日期说明、快照、参考结果和校验记录。

## 条件融资研究（动态净资产上限）

默认融资买入上限为当前账户净资产的 50%，不是初始本金的固定额度。净资产为现金加持股市值减融资欠款；每笔新增融资在计入滑点和费用后验证债务上限。例如净资产 100 万允许融资 50 万，净资产 200 万允许融资 100 万。固定额度仅保留为历史对照。

L 方案以 D / H 为基础，有六种事前触发条件、125% / 150% 目标。默认 D + MA60 / MA120 趋势支持，年息 6%，初始本金 100 万元，动态净资产 50% 额度，触发后目标 150%。全区间收益 +698.07%，5 分钟最大回撤 20.11%。默认依据：26 个候选中，回撤绝对值不超过无融资 D + 1 个百分点，再按扣费后收益排序；选择偏好是在已知结果后设定，不是前瞻验证。全部候选及规则见 docs/default-selection.json。这是目标仓位，不是持仓后任何时点的绝对比例保证；价格下跌或计息可使比例漂移。

融资执行代码为 docs/finance-engine.js。8 组独立 Python 参考回测覆盖 66,898 个数值；验证融资买入后债务不超过当时市价估值、扣费后的净资产一半，并测试净资产涨跌时额度相应变化、T+1 和周末计息。

完整报告在 docs/research/financing.html。原有 160% 漂移保护及 150% 维持担保比例模型平仓线不能绕过 T+1、涨跌停或成交量限制。真实券商标的资格、集中度、额度、折算率和展期要求未逐日核验。所有策略仍属于历史探索候选，不能称为高确定性。


## 实时提示与仓位展示（2026-10-09）

- 实时图显示所选 D / H / L 的计划时点目标检查，使用截至前一完整交易日的指标和当日已完成分时点。不连接券商，不生成模拟成交账本，不推演实时强平；全仓持有基准不产生每日信号。
- 方向与起始仓位参考从 2023-10-09 起、按当前已应用参数模拟到前日收盘的账户，按提示价重新估值；更换历史回测区间不会拿较早期末的账户冒充今日持仓。这不是用户真实账户。
- live-context.json 的 date 必须与源行情交易日一致；下一交易日未更新指标时停止信号。需随历史行情和财报数据更新后重新生成。缺少计划分钟不以之后价格补造；早盘条件缺少成交额时暂停融资提示。腾讯累计均价与历史 BaoStock 5 分钟数据可能有口径差异。
- 分时信号是按当前参数重算的当日提示，不宣称已在对应时刻推送。数据源可能延迟；重载会重算，不保存实盘指令。
- 每笔成交在日线和五分钟图中独立标记；两处成交表与 CSV 均有操作前后仓位。两侧用该根 K 线原始开盘价估值，成交价另列并含不利滑点；费用和融资欠款进入净资产分母。
- tests/presentation.test.js 核对仓位记账、默认排序、真实 ECharts 逐笔元数据、信号不提前出现、缺分钟 / 缺成交额 / 指标过期保护。

## 卖出确认延迟（第三批）

## 午后买回老仓（第四批）

docs/research/reentry.html 比较三种午后买回确认，实际买回最多为当天早盘非强制卖出股数的一半，每日一次委托，受T+1、成交量与净资产50%欠款限制。6个新方案在2025至2026上半年及7月后收益均改善，但2024末冻结选择仍为不买回；季度滚动自2026起选择开盘价确认。近期仅5个实际触发，全部买后到当日收盘下跌，仍依赖隔夜/后续风险；固定年度、更早时期、独立证据未达标，默认不变。18组关闭买回与原引擎完全一致，801个前缀检查、11918笔独立账本及合成T+1/重复触发检查通过。公开逐日买卖点、前后仓位、压力、移除单事件检验与从2026-10-09之后开始的60完整交易日前瞻冻结记录。
